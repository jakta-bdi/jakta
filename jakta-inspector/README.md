# jakta-inspector

A mind inspector for [JaKtA](https://github.com/jakta-bdi/jakta) agents, in the spirit of Jason's: it records,
for every agent of a running multi-agent system, its beliefs, intentions, plans and the events it handled, step by
step, and every message the agents exchange, and shows them in a Compose Multiplatform view (desktop and browser).

See the [documentation](https://jakta-bdi.github.io/) for how to use it.
