JaKtA 1.0 is a rewrite from the ground up. The BDI model is the same, but the engine, the DSL and the
module structure are new — and multiplatform.

<!-- truncate -->

## What changed

- **Kotlin Multiplatform.** The core libraries run on the JVM, in JavaScript (browser and Node.js, also on npm as
  `@jakta/*`) and natively.
- **A coroutine engine.** Each intention is a coroutine and plan bodies are ordinary `suspend` Kotlin code:
  call functions, `delay`, wait for events, and return results from sub-goals.
- **Pluggable knowledge representation.** The engine is generic over beliefs and goals. An
  [incarnation](/docs/explanation/incarnations) fixes them: Prolog terms through [2P-Kt](https://tuprolog.github.io/2p-kt/),
  plain strings, or your own Kotlin types.
- **Skills instead of actions.** What an agent can do is a Kotlin object given to its plans through
  [context parameters](/docs/basic-concepts/skills), checked by the compiler.
- **Nodes instead of environments.** Agents live in [nodes](/docs/explanation/nodes) that deliver perceptions and messages,
  with Jason-style [KQML messaging](/docs/explanation/communication) in the Prolog incarnation.
- **Simulation.** The [Alchemist incarnation](/docs/how-to/alchemist) runs JaKtA agents in simulated time.

## Before and after

```kotlin
// JaKtA 0.x
mas {
    agent("myAgent") {
        goals { achieve("sayHello") }
        plans {
            +achieve("sayHello") then { execute("print"("Hello, World!")) }
        }
    }
}.start()

// JaKtA 1.x (Prolog incarnation)
val helloWorldAgent = agent<PrologBelief, PrologGoal, Any> {
    embodiedAs { Any() }
    hasInitialGoals { !initialGoal { Atom.of("sayHello") } }
    hasPlanLibrary {
        prologPlan {
            adding.goal { matchingGoal { Atom.of("sayHello") } } triggers {
                agent.print("Hello, world!")
            }
        }
    }
}

fun main(): Unit = runBlocking {
    mas(NodeBuilders.baseNode()) {
        node { withAgents(helloWorldAgent) }
    }.runLocally()
}
```

## Getting started

The [documentation](/docs/intro) has been rewritten for 1.x, and the [examples](/docs/getting-started/quick-start)
now live in the main repository. JaKtA 0.x is deprecated; if you are reading one of our earlier papers,
