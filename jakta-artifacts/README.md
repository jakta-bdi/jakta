# jakta-artifacts

CArtAgO-style artifacts for [JaKtA](https://github.com/jakta-bdi/jakta), a Kotlin Multiplatform framework for
BDI (Belief-Desire-Intention) agent-oriented programming.

An artifact is an environment entity with observable properties, operations and internal behaviour,
hosted by an `ArtifactNode` and used by agents through the `ArtifactSkill`, from the same node or from other ones.

See the [documentation](https://jakta-bdi.github.io/) and [main repository](https://github.com/jakta-bdi/jakta)
for setup and usage.
